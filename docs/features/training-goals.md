# 種目の長期目標と進捗

詳細分析の「目標を設定・進捗を見る」から `/goals` を開く。

- 種目ごとに目標重量・回数と期限を設定する。3か月・半年・1年の期限ボタンと日付指定に対応。
- 開始重量は指定回数以上の過去最高重量を仮入力し、変更可能。記録がなければ0kg。左右別種目は片側1回の重量基準。
- 進捗は開始日以降の完了済み実績から、指定回数以上できた最高重量で計算する。重量だけの達成では判定しない。実績未取得・通信エラー時は進捗を表示しない。
- 月末の目安は開始値から期限までを日数で按分し、設定した増量幅で切り上げる。最終期限は目標値で固定。これは計画の目安であり、成長予測や強制的な増量指示ではない。
- 期限超過、残り重量・日数、達成、一時停止・再開、終了・復帰、編集、部位フィルターを用意。
- 1種目に管理中の目標は1件。終了した目標は残し、次の目標を作れる。

## 保存

この実装の目標はブラウザのlocalStorage `repwise-training-goals-v1` に保存する。サーバー保存や端末間の自動同期は行わない。同じ公開URLでもブラウザ・端末・オリジンが異なると別の保存領域となる。

JSON書き出し・読み込みでバックアップと引き継ぎが可能。同じIDは既存データを優先し、別IDの管理中目標が同じ種目に重複する場合は全体の読み込みを停止する。不正な保存データ・容量超過・競合時はエラーにし、保存成功と扱わない。別タブの変更は再読込し、更新日時が異なる同一目標への保存は拒否する。localStorageの同時書き込み自体はトランザクションではない。

トレーニング実績は既存の全期間分析APIから読み取り、完了・削除除外・左右別重量換算の既存ルールを利用する。フォーカス復帰や同期キューの変更時に実績を再取得する。DBの構造変更・migration・実ユーザー記録への書き込みは不要。

## 検証

`pnpm typecheck` / `pnpm lint` / `pnpm test` / `pnpm build`。

ブラウザではテスト用GET応答のみで375px・390pxを検証：登録、編集、再読込後の保持、一時停止・再開、終了・復帰、JSONバックアップ・別コンテキストへの取込、月末目安、回数条件を満たす達成判定、横はみ出しなし。実DB/APIへの書き込みは行わない。

## ホーム・記録との連携

PC・モバイルのメニューから「目標設定」を直接開ける。編集フォームは画面内のモーダルダイアログに表示し、保存できない理由もフォーム内に表示する。期限の3か月・半年・1年ボタンには選択状態があり、期限の日付を手入力すると解除される。

ホームは期限の近い管理中の目標を3件まで表示し、全件は目標設定へ移動する。期間集計（直近7日・30日）、前回のトレーニング、重複する履歴カードはホームから除去。履歴へのメニューとカレンダーは維持する。

記録画面では目標のある種目に限り保存済み進捗、目標までの残り重量、月末の目安を表示する。今回の完了済みセットは別の「保存前の見込み」として計算し、保存済み達成率とは混ぜない。左右別では片側重量と少ない方の回数を使う。目標変更・フォーカス復帰・同期キュー変更時に表示を更新する。これらの表示処理は目標も実績も書き換えない。
